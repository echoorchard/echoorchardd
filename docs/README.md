# Ripe Rhythm: docs index

**Answer the pulse.** An offline rhythm-timing harvest game for Android
(Flutter + Flame). 50 rows in five seasons, Daily Row, Long Row, 20 seals,
Journal and Market Stall. No ads, no purchases, no data collection.

## Pillars

1. **The visual beat is always enough.** Sound and haptics only reinforce.
2. **One new rule per season**, taught before it is tested.
3. **Gentle failure.** Leaves regrow, restarts are free, nothing is punished harshly.
4. **Earned, never sold.** Seeds and dewdrops come only from play.
5. **Painted, not templated.** Generated gouache art and synthesised sound, all from scripts in `tool/`.
