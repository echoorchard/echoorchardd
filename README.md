# Echo Orchard

**Answer the pulse.** A cozy, offline rhythm-timing game for Android. Every
tree in the orchard pulses on its own tempo: tap it when its echo ring meets
the golden ripe band and the fruit drops into your basket.

- 50 rows across five seasons, and each season adds one rule: one pulse, many
  tempos, rest beats, wind gusts, fading echo
- Daily Row (date-seeded, offline) with a streak calendar, the endless Long
  Row, 20 seals, a Journal of stats, and a Market Stall of cosmetic baskets
  and keepsakes, all earned with seeds from play
- No ads, no purchases, no accounts, no network, no data collection

## Develop

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

Built with Flutter 3.47.9 (pinned in CI) and Flame.

## Generated content

Everything that isn't code is generated by scripts in `tool/` (Python 3 with
Pillow + numpy, and ffmpeg for audio):

| Script | Writes |
|--------|--------|
| `python tool/make_art.py` | `assets/images/`: season paintings, hub bands, trees, fruit, baskets, keepsakes |
| `python tool/make_store_art.py` | logo, launcher icon sources (`assets/icon/`), `store/` icon + feature graphic |
| `python tool/make_sfx.py` | `assets/audio/`: every sound effect and the two ambient loops |

Then `dart run flutter_launcher_icons` regenerates the Android launcher icons.
